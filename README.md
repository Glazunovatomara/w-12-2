# Сервис комментариев со спам фильтром
Реализован сервис комментариев, в котором:
- реализовано подставление стандартного аватра пользователя в случае, если пользователь его не добавляет 
- реализована возможность выбора указывать имя или нет
- указано время написания комментария
- реализован интерфейс преобразования имени
- реализован спам фильтр заменяющий определенные слова на ***
